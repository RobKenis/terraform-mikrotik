# CSS326-24G-2S+RM

## System

Configure static IP to `10.0.0.2` as SwOS does not support DHCP client in a VLAN. Enable `Independenent VLAN Lookup`

## VLANs

| VLAN ID | Name       | Ports     |
| ------- | ---------- | --------- |
| 1000    | Management | 2, 10, 24 |
| 1100    | Trusted    | 2, 18, 24 |
| 1200    | Guest      | 2, 24     |

## VLAN

| Port | VLAN Mode | VLAN Receive  | Default VLAN ID | Force VLAN ID |
| ---- | --------- | ------------- | --------------- | ------------- |
| 2    | strict    | only tagged   | 1               | no            |
| 10   | enabled   | only untagged | 1000            | no            |
| 18   | enabled   | only untagged | 1100            | no            |
| 24   | enabled   | any           | 1000            | no            |
